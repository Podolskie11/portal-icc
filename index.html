Pasang di telefon

Pasang Portal ICC sebagai aplikasi supaya ia sentiasa ada di skrin utama telefon anda.

  1. Buka halaman ini dalam Safari.
  2. Tekan butang Kongsi di bawah skrin.
  3. Pilih Add to Home Screen (Tambah ke Skrin Utama), kemudian Add.
  1. Android: buka dalam Chrome → menu ⋮ → Install app / Add to Home screen.
  2. iPhone/iPad: buka dalam Safari → Kongsi → Add to Home Screen.
  3. Komputer: Chrome/Edge → ikon pasang di hujung bar alamat.

Masalah log masuk?
  1. Pastikan anda log masuk ke Google dengan akaun @uthm.edu.my, bukan Gmail peribadi.
  2. Jika pelayar ada lebih daripada satu akaun Google, sistem mungkin gagal dibuka. Gunakan tetingkap Incognito, atau profil pelayar yang hanya ada akaun UTHM.
  3. Kali pertama masuk, isi borang Mohon akses. Admin akan aktifkan akaun anda.
  4. Setiap sistem ada peranannya sendiri. Akses di satu sistem tidak bermaksud akses di sistem lain.
